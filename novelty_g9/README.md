# G9 — Test identity is not test-name identity

Research candidate, 25 November 2026. **MR31R9-EP2 remains unchanged.** No independent execution of the benchmark tests is claimed.

## Main result (frozen G8 cohort)
From the 13 distinct tasks with an all-FAIL_TO_PASS-name local positive receipt associated with the final recorded patch, reconstruct the candidate and official-test file versions independently from the original base commits using exact git apply. All 13 needed base files were recovered and all 15 focal node definitions were found in the official reconstruction. Fourteen of 15 named-node function ASTs differ in the candidate reconstruction; 12 of 13 tasks contain at least one such difference. Ten tasks retain a base test file that differs from the official test version. No exact entire gold test-file diff block or full file-byte equality was found among the focal definitions. One focal AST matches but this is not full semantic or environment identity. Of six benchmark nonpasses, five have at least one focal AST difference. All seven benchmark passes also contain at least one difference, so the observed AST difference is not a classifier for benchmark failure or proof of its cause. Five tasks show every required FTP and PTP name in one local positive receipt (one has an empty PTP set); three do not pass the benchmark. The analysis neither assigns fault nor infers deliberate manipulation.

## External archived submissions
The independent official submission archives have a fixed 500-task frame each. Gemini 3.5 Flash: 441 complete artifact triples, 438 admitted after exact submission/evaluation-patch matching, official verdict reconciliation and full test-name partition validation; 59 missing triples, two name partition mismatches, one not applied/no report. Admitted outcomes: 357 pass, 72 FTP-only nonpass, 4 PTP-only nonpass, 5 both. Among 115 admitted runs with a recognized local positive receipt, 18 are benchmark nonpasses (16 FTP only, 2 both); only one has a recognized named positive line and no exact final-diff snapshots were found. This is a historical receipt comparison, not a replication of final-state or exact-name/AST association. GPT-5 mini and Devstral Small each have 500 complete artifact triples; 486 and 451 nonempty matched submission patches respectively, but none passed the original report-verdict schema gate. Keep these cohorts HOLD; do not treat this as model failures or silently reinterpret the report schema. The archive loader initially used inconsistent dictionary keys, was corrected, and the final run reconciled artifact counts.

## Originality and boundaries
Test inadequacy, repair overfitting and SWE-bench's use of hidden test patches are established. See https://doi.org/10.1145/3106237.3106274 and https://openai.com/index/introducing-swe-bench-verified/. The narrower contribution is empirical evidence that exact local test identifiers associated with an identical recorded candidate patch can correspond to different statically reconstructed reference test definitions. This supplies an evidence-identity counterexample to treating test names as a certificate, not a novel general theory or proof of semantic inequivalence. Reference verdicts can reflect infrastructure and benchmark limitations. Independent test reexecution and full environment identity remain unverified.
